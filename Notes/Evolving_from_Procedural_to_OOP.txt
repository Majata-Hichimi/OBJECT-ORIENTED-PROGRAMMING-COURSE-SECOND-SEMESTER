Procedural Programming is a programming paradism that is concerned with the use of sequences that execute in order to solve a problem.Problems are broken down into smaller sub problems that can be solved by implementing a sequence of function.Functions allow for data to be passsed upon them when they are called or use local variables in order to solve problems.The key characteristics of procedural programming is that it focuses on steps and on how to use them to solve a problem,data and functions are kept separate in procedural programming and the execution flow of a program is easier to track.The applications of procedural programming are system programming,automation,scientific computing,simple tools,education and legacy systems.Examples of procedural programming languages are C,Pascal and Cobal.Real world systems that use the procedural programming paradism are the Linux Kernal and Git.
